# EditExcel

برنامج WPF / C# يفتح ملف GitHub في **Microsoft Excel المثبت على Windows**، ويرفع النسخة المحفوظة تلقائيًا عند الضغط على **Ctrl + S**. لا يعدّل محتويات XLSX أو تنسيقه: ينقل الملف كاملًا كما حفظه Excel.

## التشغيل

1. فك ضغط ZIP بالكامل، وشغّل `EditExcel.exe` من مجلد `App` (النسخة الجاهزة Windows x64، لا تحتاج تثبيت .NET).
2. يلزم Microsoft Excel مثبتًا، واتصال إنترنت، وحساب يملك كتابة على المستودع. البرنامج لا يتضمن ترخيص Excel.
3. الرابط الافتراضي: https://github.com/waleedzidan2020/editexcel/blob/main/data/schools.xlsx
4. اضغط «إنشاء Token». اختر **Fine-grained personal access token**، واجعل Resource owner حسابك، ثم **Only select repositories → editexcel**، وأضف **Repository permissions → Contents → Read and write**. حدد مدة صلاحية مناسبة وأنشئ التوكن.
5. انسخ التوكن إلى خانة GitHub Token داخل البرنامج. لا ترسله في محادثة أو ترفعه إلى GitHub. فعّل «تذكّر الدخول» ليحفظه البرنامج مشفّرًا بحماية Windows بعد نجاح الاتصال؛ لن تحتاج إدخاله عند كل تشغيل. أو استخدم تسجيل الدخول من المتصفح وفق [إعداد GitHub App](GITHUB-APP-SETUP.md).
6. اضغط «اتصال وفتح Excel». عدّل **الملف الذي فتحه البرنامج** ثم اضغط **Ctrl + S**. انتظر رسالة «تم رفع آخر نسخة محفوظة إلى GitHub بنجاح».
7. اترك EditExcel مفتوحًا أثناء العمل. عند الانتهاء احفظ Excel، انتظر تأكيد الرفع، ثم أغلق Excel والبرنامج.

الملف `data/schools.xlsx` بدأ من المرفق `جدول_المدارس(4).xlsx`، باسم أبسط للرابط، وقد يتحدث مع الحفظ والمزامنة. تنسيق الملف والروابط والاتجاه لا تتغير بسبب البرنامج.

## تحديث 1.1

- حفظ الدخول باستخدام Windows DPAPI لحساب المستخدم الحالي، واستعادته، وحذفه من الجهاز.
- تسجيل الدخول بالمتصفح عبر GitHub App Device Flow، مع كود تحقق وإلغاء وانتظار مطابق لحدود GitHub.
- يتطلب الدخول بالمتصفح تسجيل GitHub App وتثبيته على الريبو وإدخال Client ID العام مرة واحدة؛ التفاصيل في `GITHUB-APP-SETUP.md`.
- عند انتهاء أو إلغاء صلاحية الدخول، تتوقف المزامنة ويطلب البرنامج إعادة تسجيل الدخول، دون حذف التعديلات المحلية.
- البناء واختبارات تدفق الدخول الوهمية والمزامنة تُجرى على Linux. تشغيل واجهة Windows وDPAPI والدخول الحقيقي يحتاج اختبارًا على Windows وتطبيق GitHub مُسجّل.

## كيف تعمل المزامنة؟

- يفحص البرنامج النسخة المحلية كل 5 ثوانٍ ويقرأها مرتين بفاصل 1.2 ثانية لتجنب رفع ملف أثناء الحفظ. يستخدم بصمة المحتوى لمنع التكرار.
- كل نسخة محفوظة مختلفة تصبح Commit على الفرع المحدد. الحفظ السريع المتكرر قد يُجمع في رفع آخر نسخة مستقرة.
- لا تحتاج Git مثبتًا. تتم العمليات عبر GitHub Contents API مع SHA للنسخة الأساسية.
- يدعم هذه النسخة `.xlsx` حتى 20 MB. يدعم الروابط العادية وRaw، والمسارات العربية والفرع الذي يحتوي `/` عند إدخال اسمه الكامل.
- استخدم Ctrl + S؛ إذا استخدمت Save As إلى مسار آخر فلن يراقب البرنامج الملف الجديد.
- المزامنة من النسخة المحلية إلى GitHub بعد الحفظ. لا يستبدل الملف المفتوح تلقائيًا عند تعديل شخص آخر للنسخة البعيدة؛ يفحص التعارض قبل الرفع. أعد الاتصال لتنزيل النسخة الجديدة **بعد إغلاق Excel**.
- فشل الإنترنت لا يمسح نسختك؛ يعاود المحاولة بعد 30 ثانية. عند إعادة تشغيل البرنامج يتعرف على التعديلات المحلية المعلقة.
- رابط عام يسمح بالتنزيل فقط؛ الكتابة تحتاج توكن صالحًا. سياسات حماية الفرع قد تمنع الرفع المباشر.

## التعارض واسترجاع النسخة المحلية

إذا عدّل شخص آخر الملف على GitHub، يتوقف الرفع دون الكتابة فوق أي نسخة. لا يوجد دمج تلقائي لملفات Excel.

1. احفظ وأغلق Excel ثم أوقف المزامنة.
2. افتح «مجلد النسخ المحلية» وانسخ `workbook.xlsx` إلى مكان آخر آمن.
3. نزّل النسخة الموجودة على GitHub وقارن النسختين في Excel، وادمج التعديلات التي تريدها يدويًا في نسخة آمنة.
4. بعد الاحتفاظ بالنسخ، احذف **مجلد الجلسة المعنية فقط** من `%LOCALAPPDATA%\EditExcel\Sessions` ثم اتصل من جديد لتنزيل أحدث نسخة.
5. انقل التعديلات المختارة إلى الملف الذي فتحه البرنامج واحفظه؛ يرفع البرنامج التعديل فوق أحدث أساس.

لا تشغّل جلستين للبرنامج على نفس الملف في الوقت نفسه. لا تعدّل state.json يدويًا. إذا وُجدت نسخة محلية بدون سجل سليم، يرفض البرنامج استبدالها. توجد نسخ `.backup-*` عند تحديث نسخة محلية نظيفة من GitHub بعد إعادة الاتصال.

## البناء من المصدر

ثبّت [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)، ثم شغّل `build.cmd` أو:

```powershell
dotnet run --project tests/SyncChecks
dotnet publish src/EditExcel/EditExcel.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish/win-x64
```

الاختبارات تستخدم خادم HTTP وهميًا ولا ترفع ملفات حقيقية. تختبر منع تكرار commits، استعادة التعديلات المحلية بعد إعادة التشغيل، التعارض، ونجاح الرفع مع ضياع الرد. تشغيل الواجهة وفتح Excel يحتاجان Windows وOffice، وهما غير مختبرين في بيئة Linux.

المراجع: [GitHub Contents API](https://docs.github.com/en/rest/repos/contents) و[نشر .NET كملف واحد](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview).
